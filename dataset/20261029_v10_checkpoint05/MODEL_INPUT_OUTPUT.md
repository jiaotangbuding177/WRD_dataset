# 模型输入输出与真实执行

模型接收总目标、企业会话、当前已知状态、真实资源和原生工具schema。原会话中的用户纠正和约束须保留；路径清单不代替未读文件内容。输出由显式理由、真实工具调用、环境中的文件产物与最终交付构成。

read/write/edit/exec由固定原生OpenClaw执行并返回真实观察；模型在自己的历史上继续探索、测试、修订和收尾。外层只投递与记录，不替模型调度，不编造工具返回。阶段拼接示例不能冒称单模型自主闭环。

训练行含messages/tools/input_ids/supervision_spans和来源、owner、质量元数据。loader把批准位置设labels=input_ids、其余-100，并给loss_weights；字段、范围、token与原文SHA绑定。原R、历史累计摘录和新作者理由明确分账。新输入或原生动作投影不声称等于原Teacher执行条件。

当前仅组件过程资料，单原生自主A—D示范0、正向合格保留0。训练和服务均未启动；详细预算和验证见TRAINING_PLAN.md。
