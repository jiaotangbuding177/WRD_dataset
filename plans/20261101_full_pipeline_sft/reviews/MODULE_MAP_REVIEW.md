## 主训练定位

这份数据最适合训练 **WRD技能沉淀策略与执行模型**。统一学习接口是：

**当前会话／需求与资源状态＋已经发生的反馈 → 可审计的决策依据＋下一步工具动作或流程决定。**

它把需求纠正、资源制作、测试反馈和收尾选择连接在同一监督接口中。中间记录的价值在于训练“为什么在这个状态采取这个动作”，使模型能够围绕技能沉淀持续作出有证据的下一步选择。

当前可用目标1250＝418契约辅助＋205既有过程＋576条件决策＋51资源支持构造；过程课程832＝205＋627。以下按训练任务映射，任务之间可以共享同一目标，不能将表内覆盖数相加。

## 对418个契约目标的实际schema核对

已读取实际训练行。每个正目标的JSON结构为：

```json
{
  "contract_delta": [
    {"op": "...", "field": "...", "value": "...", "evidence_ids": ["..."]}
  ],
  "next_decision": ["..."],
  "evidence": [
    {"evidence_id": "...", "message_id": "...", "char_start": 0, "char_end": 1, "quote": "..."}
  ]
}
```

字段/决定是可核查的训练对象。实际累计高频字段：declared_file 202、named_skill 147、output_format 80、regenerate_or_recheck 44。next_decision包括资源身份与可用性核验259、明确契约增量应用184、范围限制遵守11，以及用户反馈处理与格式冲突澄清。这些是字段或决定出现次数，非互斥样本数。

据此，418的最准确价值表述是 **需求更新、用户纠正保留、资源/技能身份定位与证据对齐**。复用收益排序的训练材料可以继续从路线与消费证据加工；当前这418直接支撑路线选择的输入理解层。

## 理由、结果与训练目标的接线

- 原记录中的R与原动作保留原来源；构造解释标为新作者依据。两类共同用于证据约束过程SFT，来源和权重保持可追溯。
- 资源修订以同输入程序检查、精确版本SHA和实际输出授信。原版失败、修复通过、回归再失败，让修订目标具有可执行验证依据。
- 256个原条件翻转对与64个跨条件阻断对，要求关键前提变化时动作随之变化；576个无关扰动用于核对稳定性。
- C的现成训练目标是 **解释已有质量/成本证据并作决策**。独立盲评打分器是单独的评分监督任务，可继续从经校准的评分记录形成专门训练集。
- 条件KEEP训练学习题给政策下的保留规则；实际技能质量与单位合格技能成本用于训练后pipeline验收。训练标签类型与真实运行指标分别记账。

## 后续可加工的训练形式

现成完整训练课程直接使用SFT。已有原始记录和反例还可继续形成两类派生数据：

1. **偏好优化数据：** 固定同一输入、资源和版本，将正确/错误决策、有效/无效修订整理为完整chosen/rejected响应，再进行成对验收，可用于DPO等偏好训练。
2. **检索与路由数据：** 将需求、已使用技能、资源适用边界与消费结果整理为query—skill/route的正负对，可训练技能检索、候选重排与路由选择。

这两类是继续加工的明确方向，当前直接可加载的交付物是具有逐token监督与四features的SFT课程。它的首要训练价值，是把已有技能沉淀经验转成统一的、证据约束的状态转移学习任务。
