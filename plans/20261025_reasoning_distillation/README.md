## 目标与最终模型输入输出

用户要求的最终系统是：同一14B学生在固定原生OpenClaw中，从一次完整企业会话及资料输入，自主探索、操作工具、复现资源、选择真实验证需求、比较有/无技能执行证据、修订、筛选、封装skills。8B是相同数据与曝光下的对照。最终输入包括完整企业会话及纠正、附件、已有技能库、可用演化需求池、任务目标与权限/时间/算力边界；最终输出为版本化独立技能包、适用边界、验证/成本摘要及retain/defer/no_value等明确结果。制作和审查轨迹在包外保留。

模型逐轮处理“当时可见历史与工具观察→原始思考/解释→动作或阶段决策”，原生环境执行真实工具并反馈；不另建Agent循环。分项替换maker/prepare/review的成绩只说明分项能力，必须再做单次业务输入、无人工阶段提示的完整自主闭环验收。

## 数据入口与丢失口径更正

原始记录优先于冻结导出。旧导出包含reasoning清洗逻辑、旧编译器固定enable_thinking=False且单completion；即使旧summary显示删到0块，也不能证明外部原响应没有思考。本轮已在历史制作记录和Actor记录的response.raw.json中定位choices[0].message.reasoning_content正文，必须原样恢复并绑定同次request、response、工具和后续观察。公开摘要不能代替已保存的原始思考。日志原始字节与SHA保留，不回写原文件。

数据范围包括：当前完整原生阶段母表、此前漏列的D/E历史WRD制作根、原始模型请求/响应及工具轨迹、资源版本、试做/审查与修订关联。历史自建执行条件的记录保留环境标签，不冒充现行OpenClaw同条件执行；它们可以训练领域判断/资源设计，协议动作需单独验证或声明映射。旧执行代码仅作证据读取，绝不运行。

## 五类监督单位

1. **原始思考—行动记录**：准确的request历史、真实reasoning字段、同次content/tool_calls及原生返回；每个段标明JSON pointer/响应SHA/时间/作者角色。
2. **完整阶段轨迹**：screen/make/prepare/review及必要Actor观察，包括真实失败、诊断与修复。完整记录不保证每步正确，明确错误动作只作masked历史。
3. **资源构建和修订**：实际旧版本→当时反馈→真实修改→后续复现/结果。后续成功仅作后验标签，不放进修复前输入。原write/exec内程序也是重要生成目标。
4. **全流程状态转换**：区别observed_model_decision、actual_orchestrator_policy及assistant_derived_annotation。原pipeline自动派prepare/actor/review不能冒称模型自主选择下一阶段；必须额外训练/验证这些转换与可执行动作。
5. **停止/取舍记录**：reuse/new/merge/defer/no_value及retain/revise/reject/defer，保留原标签与证据审核标签，正确拒绝/暂缓是有效行为，不能只挑留存赢家。

同一响应/资源SHA/父样本的多视图不算新独立任务。数量同时报告来源组、完整轨迹、原响应、非空目标、原思考目标、监督token、实际曝光token和完整长度覆盖。

## 因果可靠性与监督准入

每条目标必须能回答：谁在什么时候、针对哪个真实输入、在可见哪些证据后输出；工具返回属于哪次调用；资源版本当时是否存在；后续结果何时产生。request中的原始历史是优先输入，不按最终目录内容反填。请求/响应关联不明、缺工具返回、时点不明、截断不可补的记录保留定位与缺口，不静默拼接。

时间/版本/调用关系可通过机械核验；思考逻辑和业务判断是否正确还需要语义审核。完整日志不能自动证明每步推理忠实或正确。原教师标签按observed silver描述，人工gold与独立复核另列；结构通过不得改名语义gold。

将审核分为：可用于过程模仿的可追溯教师记录、结果支持的强示范、真实失败/修复历史、未决记录。未审不等于低质量，也不能直接当已审正例。弱记录的使用比例、loss权重和明确错误mask在训练manifest中冻结，不用公开状态替代质量判断。

## 训练算法：思考、行动与决策分段蒸馏

选Qwen/Qwen3-14B主、Qwen/Qwen3-8B对照，沿用锁定revision；它们已有通用语言/推理基础，本训练学习WRD的领域决策和工具闭环，不从零学习语言。原始思考与动作联合监督，输入的system/user/tool观察/pad均不计算loss。每个原生目标只有一个loss归属，其他历史可作为上下文。

对同一监督单元，分别计算原始思考R、可见解释E、实际行动/资源A、阶段/停止决定D的token均值NLL。初调研的三段方案进一步依据实际原生E与真实R分离，建议起点为：

`L_unit = 0.25 L_R + 0.10 L_E + 0.45 L_A + 0.20 L_D`

各实际存在片段先做token均值，缺失片段重新归一，再作父样本和阶段平均；格式控制另加0.02辅助loss。数组中F基础权重0.2只是编译结构标注，不等于已经实现上述分段/阶段训练目标，不能把默认全token平均SFT声称为本算法。

当前数组E/D的划分依据是是否带原工具调用的正文载体，D包含无工具正文而不只是语义上的正确决定；write内reason也可能属于A。业务决定的规范性仍需独立标签/真实结果，不能把这些结构码包装为全量正确性过程监督。详细定义见DATA_LOADING_AND_DELIVERY.md。

缺少某种原始片段时只对实际存在且准入片段重新归一化，不凭空填推理。派生依据单列来源/预算，不称原思考。该分段意在避免长CoT/长代码或大量read/poll按长度独占训练信号；随后按父样本和A/B/C/D阶段均衡，建议阶段权重0.20/0.35/0.30/0.15。所有系数是起点建议，要用消融验证，不冒称文献最佳值或已实现训练器。

稀有决定在固定总监督预算内提高采样，最多3倍，不再叠加相同类别loss倍率。Actor原始轨迹主要作为C证据，明确角色辅助目标最多10%；现行沉淀与历史协议分别分层计量。首轮主要监督teacher文本，不拥有教师logits，不称KL蒸馏/GKD/SOD。

课程一：可追溯原始思考＋决策＋工具行动的短自洽片段（4K/8K），先学事实与约束、方案选择和正确协议。

课程二：资源构建及完整多轮阶段（16K，兼容后32K），覆盖成功/失败/诊断/正确终止；完整阶段不被拆成毫无联系的孤立动作。

课程三：真实反馈修订＋跨阶段自主决策，输入真实旧版本/已发生观察，学习下一合法动作、局部修改和停止。主预算以准入父样本一遍规范化曝光为起点，修订额外监督不超过0.5倍；派生摘要/控制视图最多替换主预算20%，不能靠重复生成改写凑数据量。

原思考视图在三段中持续混合，不能热身后完全被大量无显式R的原生工具动作覆盖。以原R占监督曝光约10%作候选目标，每个原思考父样本最多两次规范化曝光，所有重放仍计入总1.5倍预算和实际成本；达不到目标时报告实际比例，不靠无限重复把8个原来源伪装成大量独立经验。旧EWI的READ/UPDATE/TRY/FINISH是历史策略任务输出，不直接改名为现行原生工具调用；现行工具语法仍由实际原生轨迹监督，协议投影必须单独声明和验证。

同条件可靠chosen/rejected才考虑短程DPO；不同反馈前后版本不能直接配对。离线SFT之后仍须检验学生自身错误分布上的表现。需要学生rollout/教师分布的on-policy/SOD/ReST增强只能未来另获授权后做，当前不采样或训练。

## 原始思考模板与loss mask

Qwen3官方模板通常省略历史thinking；因此“JSON有reasoning”不等于监督token有reasoning。v4要求逐目标验证当前response中完整原思考及动作实际进入模板与loss。源档保存所有历史思考；训练历史呈现策略与未来运行保持一致，不能为了兼容模板删源。

旧17条前缀异常包括连续assistant和正文孤立think分隔符；不得靠最长公共前缀或字符偏移硬切。采用单次完整渲染后的显式segment span或可证明等价的目标视图，校验tokens能恢复被监督的原片段、没有任何tool结果进入loss、没有未来内容进入prompt。14B/8B分别使用锁定官方资产，逐ID核对token与span一致，不凭“同一分词器”跳过验证。

长序列统计按输入＋目标总长度；超过32K的原始轨迹完整归档，不静默截断。可另建有时点证据的状态/检索视图，但其覆盖率与原始完整前缀分别报告。公开与受控数据都纳入分母，不只报告顺利通过的小子集。

## 原生动作空间是完整自主的必要条件

目前原pipeline由外层派发多个stage，不能只训练next_stage字符串就宣称自主Agent。要确认学生通过原生现有工具能够读取来源、生成/复现资源、发起允许的试做、收到真实结果并继续决策。sessions_spawn等工具必须有实际schema/权限和结果证据；若高层双臂试做接口尚不可用，该项是待解决接口缺口，不能靠训练文件伪造已解决。本轮不写替代执行器/新工具循环或暗中改生产环境。

## Spark参数与预算

BF16 LoRA r32/alpha64/dropout0.05，attention和MLP线性层；AdamW主LR1e-4、反馈精修3e-5、warmup3%、cosine、clip1、weight_decay0.01，micro1×acc16、gradient checkpointing、use_cache=false、SDPA候选。单台Spark顺序训练两模型，ARM64/multi-arch NVIDIA容器先锁digest与依赖。32K峰值统一内存/真实吞吐未经实测，QLoRA只是后备候选。

实际预算必须从最终processed tokens、监督tokens及长度桶的实测完整训练步吞吐计算；masked长前缀仍耗算力。当前不提供编造的小时或人民币。所有编译/标注/训练调参/失败/OOM/修订/评审/教师兜底计入总成本，旧历史API支出单列不重复当新增。

## 验收与为什么有望得到目标模型

训练信号逐项对应目标行为：原思考教基于证据规划，真实工具动作教环境操控，工具观察教状态更新，失败修订教恢复，跨阶段控制教自主推进，停止/封装教可消费交付。原生运行环境与实际验证保留，是把学到的文本策略转成可执行行为的必要条件；仅靠最终技能文件无法覆盖这些职责。

验收同时包含源档恢复完整性、因果/模板/mask、各分支和思考覆盖、独立来源隔离、阶段任务，以及新来源从单次输入到完整技能的自主闭环。最后一项不能用每stage有人提示的成绩替代。正式226/250与其反馈不反哺训练、开发或阈值。

比较同期教师T、S14、S8；14B最小消融为普通动作SFT、去原思考监督、去真实修订/控制课程，尽量固定来源与监督曝光。固定消费Actor比较技能质量，学生自主操控接口另测；若评模型同时承担Actor，应做独立变量试验而不混入主归因。

沿用独立五维Q、TSR、K_Q/K_R/K_G，主每合格技能成本包含全部失败/修订与训练摊销。建议业务目标为Q/TSR相对教师容忍5分/5个百分点、运营CPQS降30%，须开发校准及区间验证，不能承诺一定达到。拟24独立来源组×2消费、T/S14/S8基础72制作/192消费槽位；来源不足或区间过宽不能写成已证非劣。

这份方案给出达到目标的机制与可证伪检验，不在训练前保证蒸馏效果。若实际思考量、独立任务/分支或自主动作接口不足，必须在最终READINESS中明示并补齐；不能把训练不具备这些条件的数据包包装为完整目标已可达。
