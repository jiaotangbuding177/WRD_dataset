# v10可靠主训练集：独立重标与干净闭环重构

用户要求继续主动调整素材并交付可靠、足量主集。本轮保留原226/新H/静态dev-test隔离、不训练权重；必要数据重建推理按首批≤12、累计≤120原生阶段实施，费用及失败单列。该上界是本轮实施约束，不是结果保证。

## 要改变的准入方法

v9以最终文件精确write为主的规则遗漏了大量有价值的过程。v10按证据/路线、资源构建、执行能力、观察诊断、实际修复、评审和封装停止分别审核，授予具体片段信用。版本试跑证明局部效用，不能认证该轮所有思考或断言。源正确、语义正确、工具有效、版本效果与总成本分开。旧受保护轨迹保全但不转写为干净teacher答案。

## 实际素材利用

1. 重新核现有所有train源与可合法新分配的长源；私有真实业务附件按字节血缘分组，公开builtin不机械连接全部样本。缺件、原业务真附件、公开学习资料和明确重构夹具分开。
2. 原whole-clean Actor优先选真实no_skill且learned_skills为空者，冻结E实际outputs及inline代码，不只依赖旧bundle索引。新rubric只看原题/输入，再独立核真实产物/反馈，不用旧review或Q结果反标。
3. 新A/B/D以干净完整会话、可证公开或源内资源、经重评的真实执行记录重构。实际原生验证程序、模板与消费接口，再用独立原生Actor试跑、反馈和修订形成主过程。
4. 经验证的新干净base资源可生成显式bug/错误封装等训练题；逆补丁和测试实际验证，标注来源明确，不把合成题数算独立业务来源，不伪造原Teacher思考/环境回执。

## 交付质量与规模

工程目标：≥2000非平凡主目标、≥100万主监督tokens、≥50不同干净来源群、≥12工作机制族，并提供真实make→trial→feedback链。目标只是准备门槛，不能据数字保证14B/8B效果；逐阶段/分支及独立来源覆盖优先于行数。未达时继续在既定范围内补缺，不用辅助/模板/重复窗口凑。

原始全文、可读R、工具、失败和修订保全；新增解释/推理标注与原Teacher字段分开。32K之外允许基于过去证据的状态checkpoint视图，保留完整祖先及原全文，不能提前包含未来试跑结果。训练只监督获证具体片段，实际labels/weights与两套tokenizer逐例核验。

## 原生执行与边界

仅使用固定OpenClaw原生loop和native.py，外层只投递、启动、记用量与事后评分。独立新lane不抢现消融0—9；实际容器<8且RAM≥7GiB才准入。logging只透传原HTTP字节并只读导出all-session，不改模型、工具/返回、skills发现或账户规则。先一次技术probe确认capture与原生子Agent，单列成本；同workspace子Agent不当公平隔离两臂。禁止邮件/日程/远端真实写入等副作用。

14B主、8B对照保持。数据充分后仍需用户授权训练；未来效果以学生自身历史的原生闭环TSR、独立Q及每个合格技能总成本验证。当前不作训练收益声明。
