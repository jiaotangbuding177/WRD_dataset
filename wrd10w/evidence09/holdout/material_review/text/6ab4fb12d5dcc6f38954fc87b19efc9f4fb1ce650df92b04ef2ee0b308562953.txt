销售佣金提成管理制度
第一章 制度目的
为规范冰美肌MJ6产品销售过程中的设备销售佣金、耗材销售激励、内部销售提成及渠道合作费用管理，防止商业贿赂、虚假业绩、佣金套利、利益输送等行为，保障公司、客户及合作伙伴合法权益，制定本制度。
第二章 适用范围
本制度适用于参与公司MJ6产品销售、推广及客户拓展相关工作的个人及组织，包括：
（一）
外部
合作方
外部合作方不限于个人或公司主体，包括但不限于：个人销售顾问；行业资源合作伙伴；
美容
机构推荐合作方；渠道代理商、经销商；市场推广服务机构；其他经公司认可并备案的业务合作主体。
外部合作方须基于真实业务贡献获取佣金，公司禁止任何无真实业务贡献的挂名合作、利益输送或佣金套利行为。
（二）内部销售提成人员
内部销售提成适用于公司全体员工。
特别地，
以下人员如参与客户资源引荐或业务支持，不享受销售提成：
公司股东；
董事、监事；
已通过投资收益方式参与公司利润分配的相关人员。
员工可基于以下实际贡献获得销售提成：
独立开发客户资源；
推荐有效商业机会；
协助推进客户成交；
参与商务谈判、项目落地；
完成公司认可的销售支持工作。
内部员工销售提成按照公司销售提成政策及贡献认定规则执行。
销售激励体系合规原则
公司建立“外部
合作
佣金+内部员工提成”的双激励体系：
（一）外部
合作方
佣金原则
外部合作方佣金基于“真实客户来源 + 实际业务贡献 + 合规审批”原则执行。
禁止：
虚构合作主体领取佣金；
员工借外部合作方身份套取佣金；
外部合作方无实际贡献获取佣金；
外部合作方与内部员工私下利益分成。
（二）内部提成原则
内部员工销售提成遵循“全员参与、贡献导向、结果激励”原则。
但必须满足：
1. 
客户来源真实；
2. 
贡献过程可追溯；
3. 
提成比例符合公司规定；
4. 
完成审批流程。

第四章 外部合作佣金反商业贿赂管理
外部合作方获取佣金必须满足：
1. 完成合作备案；
2. 与公司签署《代理服务合同》或相关业务合作协议，明确双方合作内容、服务范围、佣金标准、结算方式及双方权利义务；
3. 按照国家相关法律法规及公司财务管理要求，向公司提供合法有效的发票或符合财务入账要求的凭证。未提供合法票据的，公司有权暂缓支付相关佣金；
4. 完成客户报备；
5. 提供真实客户来源证明；
6. 参与实际商务推进；
7. 经销售负责人、财务及管理层审核。
佣金支付原则：
1. 公司仅向完成合同签署、备案审批及实际业务贡献确认的合作方支付佣金；
2. 佣金支付对象原则上应与代理服务合同签署主体、发票开具主体保持一致；
3. 禁止通过个人代收、第三方代收、虚假服务费等方式进行佣金支付；
4. 禁止将佣金支付给与业务无关的个人或组织。
禁止：
1. 虚构中间人领取佣金；
2. 员工指定亲属或关联人员套取佣金；
3. 外部人员无实际贡献获取佣金；
4. 通过佣金形式向客户返利或输送利益。
第五章 内部销售提成管理
内部销售提成按照“谁开发、谁维护、谁贡献、谁受益”原则执行。
禁止员工：
1. 冒领他人业绩；
2. 虚构客户开发过程；
3. 与外部人员串通分配提成；
4. 将个人利益与渠道佣金绑定；
5. 私自向客户承诺返点、回扣或利益。
第六章 客户归属及佣金分配管理
客户必须进行报备登记。
认定原则：
1. 外部合作方首次提供有效客户，并持续推动成交，可享受对应佣金；
2. 内部销售独立开发客户，享受内部销售提成；
3. 内外共同开发客户，应提前确认贡献比例；
4. 未备案客户发生争议时，公司根据客户接触记录、商务过程及实际贡献判定。
禁止重复申报、抢单及虚假认领。
第七章 佣金及提成审批流程
所有佣金及提成必须执行：
业务申请 → 销售负责人审核 → 商务核验 → 财务审核 → 总经理审批 → 发放。
禁止：
1. 私下现金支付；
2. 支付至非合同约定账户；
3. 无合同、无订单、无服务依据支付；
4. 员工代收外部佣金。
第八章 特殊利益冲突管理
为防止内部员工与外部合作方形成利益输送，公司规定：
第一条 禁止员工行为
员工不得：
注册或控制外部合作主体获取高比例佣金；
指定关联人员作为外部佣金领取主体；
将自身应得销售提成转移至外部合作方
或其他内部员工
；
与外部合作方约定私下返还、分佣。
第二条 关联关系申报
外部合作方如与公司员工存在：
亲属关系；
投资关系；
经济利益关系；
必须提前向公司申报。
未申报造成损失，公司有权取消佣金、追回收益并追究责任。
第九章 违规处罚
1. 一般违规：
取消相关佣金及提成，追回违规所得。
2. 严重违规：
包括虚假订单、虚构客户、串通套取佣金，公司可解除劳动关系或合作关系。
3. 商业贿赂行为：
包括收受回扣、向客户输送利益、利用销售费用进行利益交换，公司将依法追究责任。
第十章 渠道合作伙伴承诺
所有外部合作方须签署《反商业贿赂承诺书》。
合作方不得：
1. 向客户提供非法利益；
2. 要求公司员工违规操作；
3. 通过虚假服务获取佣金。
违反规定，公司有权终止合作并追回损失。
第十一章 附则
本制度由销售部、财务部、人力行政部共同监督执行。
本制度自发布之日起实施。
